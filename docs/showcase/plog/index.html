把一次出门，贴成一页。

照片、手写小字、纸条和涂鸦，把零碎的小事留在一起。密集一点，安静一点，都可以跟着你的照片来。

日落以后，海边还没散场。

路上的落日，海边的秋千，还有一张眨眼的照片。亮色爱心与几笔星月，把夜晚的小片段连在一起。

五张照片，几句小注释，留住夜晚的不同表情。想做手账时，可以按自己的照片选择这样的表达。
