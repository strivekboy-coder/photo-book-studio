# 小红书文案草稿

标题：我给相册 Skill 加了 Plog 模式

把照片做成相册这件事，我又往前折腾了一点。

Photo Book Studio 现在除了做相册，也加入了 Plog / 手账本模式。旅行、周末出门、吃饭看展的小片段，可以整理成一张或几页手账。

还是先看照片，再决定构图、字体和装饰。纸条、票根、小涂鸦和贴纸，尽量跟照片里的内容联系起来；原照片保留，选中的照片都放进去。

这次还加了一个我很想要的小功能：Plog 做好后，可以在网页预览里自己微调。拖动图片、改大小和角度，移动贴纸，修改文字、字号和颜色。不想自己调，也可以继续通过对话改。

创意处理也多了三种：信封旅行拼贴、主体突破画框、三照片纸感拼贴。加上之前四种，制作时会根据照片和许可挑合适的，不要求每页都用效果。

成品可以按需要导出分享图片。普通相册仍然从问卷开始，Plog 是想做手账时才启用的新模式。

它是一份给 Codex 用的开源 Skill。作品展示、完整流程和安装说明放在 GitHub：strivekboy-coder/photo-book-studio。
