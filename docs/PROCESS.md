# Photo Book Studio：完整使用流程

这是制作照片相册与可选 Plog／电子手账的 Codex skill。普通相册仍是默认路线；不是上传旅行照片就自动启用手账。用户明确要求 Plog、手账或提供这种风格参考时才启用。主题、视觉风格与成品用途分别记录：印刷相册里的手账风仍遵守相册与印刷流程。

## 普通相册：第一步就是问卷

新相册在导入、编排、生成之前，先使用 [完整固定问卷](../skills/photo-book-studio/references/intake-questionnaire.md)。用户已经回答的题不重复问，创意处理的许可分别询问。问卷共15题及可跳过的6b：故事与对象、成品、版型、选图、上传方式、页面节奏、预算/页数、视觉风格、文案来源、文字语气与语言、基础修图、贴纸、封面、撕纸、艺术衍生、照片简化。回答可简写，也可接受推荐项。

1. **问卷优先。** 未明确的重要事项再补问；已有答案不重复问，后续批次不重跑首次问卷。
2. **保存答案。** 将明确回答、接受的推荐、推断与未知项区分记录到 `project/brief.json`，再开始导入和制作。
3. **建立照片清单、读照片。** 记录原文件身份、尺寸、方向、分辨率、拍摄时间和校验值。看所有新图的联系表，对人物边缘、重要画面和疑难裁切看大图。原图只读。
4. **按事件与故事分组、规划篇幅。** 时间线确定叙事顺序，同一天可以为画面流动调整。事件不机械等于一天或一跨页。每张选图默认出现一次，不能因为相似或难排而舍弃。
5. **决定视觉方向。** 选择、修改或新建版式。编辑式、诗意图文、拼贴和 zine 是参考结构，不能限制新参考；疏密、大图、小片段和安静停顿共同形成节奏。根据实际文案比较字体，检查缺字与可读性。
6. **写真实文案。** 保留用户提供的事实、名字、玩笑和情绪；没有文案时，只写少量可见事实草稿，不编造日期、关系或经历。
7. **完成普通图文编排。** 照片裁切、大小、对齐、色彩与文案共同构图。纸条、票根、口袋、背景、涂鸦与贴纸在有实际作用时加入，不挡脸、手或重要内容。风格与密度由用户与照片决定。
8. **评估七条创意路线。** Minimal Zine Poster、Photo Abstract Editorial、Gathered Scenes、Photo to Zine Postcard、Travel Envelope、主体突破画框、三照片纸感拼贴。全部评估，允许全部跳过；只有合适且许可允许时使用。后三条的说明与两个用户 prompt 随 skill 提供。
9. **实际渲染并修正。** 看浏览器导出的画面，检查裁切、文字、材料边缘、前后遮挡与连续页面节奏。核对每个照片身份及出现次数，证明没有遗漏。仅有数据检查通过不能算审美通过。
10. **内页完成后再做封面。** 按整本内容制作获准的插画封面，或遵循用户的照片/文字封面选择。没有生成工具时保留可行方案。单张 Plog 不要求封面。
11. **按要求交付。** 网页、图片或明确要求的 PDF；印刷需另外检查尺寸、出血、分辨率和打印方要求。只讨论 PDF 不代表要求生成。
12. **按比例继续修改。** 沿用保存的偏好与读图结果，后续批次只分析新照片，局部修改只检查相关页面，结构调整后重新核对当前页码与照片身份。

## Plog／电子手账：保留已打磨的制作方式

用户明确要求后，先补齐少量必要信息：故事/地点、照片范围、比例与用途、文案、风格参考和处理许可；不套整个印刷问卷。把答案保存在项目中，再读图、分组。

查阅灵感、材料和字体库，提炼构图关系。先确立照片、手写小字、疏密与材料的组织方式；根据照片里的物件、动作和趣味写 SVG 涂鸦，需要水彩、纸感或专门插画时才使用 imagegen。已有好素材继续复用，记录生成/复用/跳过的理由。灵感库与小型素材库继续积累，不承诺任何素材站始终可访问。

密集页面是有效选择。旋转照片、增加页数或减少内容并不直接等于设计提升。装饰可以形成亮色重点，不强制所有元素同色同质；留白与密度分别评估。再按需评估同样七条创意路线，不能把所有 Plog 都改成生成式整页图片，也不能把三照片纸感路线的45%占比套给其他风格。

原图保留并使用稳定身份。导出后看原尺寸和手机尺寸、修正，再提供成品。Plog HTML 默认携带基础编辑器：初始为预览，点击“微调排版”启用照片/贴纸/涂鸦的移动、缩放、旋转和层级，以及文字内容、位置、字号、颜色与字体修改；支持撤销、重做、微移和草稿。用户不用再次申请，也可以只通过对话修改。明确只要图片或静态页面时遵循该选择。

JPG／PNG 是分享成品，JSON／HTML 是次要的编辑备份。浏览器草稿不会自动进入 Codex 的项目导出，需先交回并应用；不能把初稿下载称为用户最新调整。普通相册暂未自动加入这套自由图层编辑器。

## 七条路线怎样选

| 路线 | 常见作用 |
|---|---|
| 极简 Zine | 封面、章节停顿、少量文字与单一重点 |
| 照片抽象记忆 | 原照与从照片提取的抽象记忆面板 |
| Gathered Scenes | 真实照片通过纤维撕纸边与插画相接 |
| 旅行明信片 | 小插页、票卡或独立纪念卡 |
| 信封旅行拼贴 | 景色作底、薄纸信封托起不同照片与主体 |
| 主体突破画框 | 矩形里保留原景，主体轮廓跨入白色留白 |
| 三照片纸感拼贴 | 主图与一横一竖辅图、薄纸层叠和大面积米白留白 |

七条都不是使用配额。普通批次以少量强候选为起点，用户明确要求整页风格时可按需要安排。生成衍生图可能改变细节；若必须保持原像素，采用真实照片图层和蒙版。新增艺术处理不自动授权替换原照，不制造原图没有的身体、枝条、人物或旅行事实。

## 下载后可以依赖什么

完整 skill 文件夹包括规则、参考、七路线政策、两个原始 prompt、独立信封适配 prompt、相册与 Plog 的初始化/清单/构建/导出工具、编辑器，以及许可随附的基础字体和少量原生 SVG。所用较大字体/材料按项目获取和缓存。初始化的新项目也有七路线政策，不依赖作者私人目录或这段聊天。

构图、读图、写作和审美仍由使用 skill 的模型执行；脚本提供身份/字体/路径检查与渲染，不会自动挑选优秀构图。没有必装第三方创意插件；生成处理需要当前环境可用的图像工具，其他 creative skills 是可选增强。不同模型和不同照片的审美结果仍需实际审稿，不能承诺固定质量。

作者提示最多在前三次有效使用出现，支持停用，无成品水印或遥测。原照片不覆盖，个人资料不随 skill 分发，发布作品需有授权。完整规则见 `SKILL.md`；具体创意选择见 `zine-policy.md`，新增 prompt 见 `creative-prompts.md`。

# Fixed first-use questionnaire

Use this questionnaire once when a user starts a new photo book. Ask it in the user's language and preserve the numbered choices. Infer answers the user has already supplied and omit only those answered items. Do not merge the creative-permission questions into one long question.

Tell the user they may reply with compact choices such as `1. ... 2C 3E`, write `由你推荐` / `recommend`, or accept every recommended option.

## 一、相册基本信息

**1. 这本相册送给谁，记录什么故事和时间范围？**

请用一两句话说明。

**2. 最终需要什么成品？**

- A. 印刷相册
- B. 网页相册
- C. 印刷和网页都要
- D. 还没决定

**3. 版型和尺寸怎么确定？**

- A. 已有打印平台或具体尺寸
- B. 方形
- C. 横版
- D. 竖版
- E. 先分析照片，再由你推荐（推荐）

## 二、照片与篇幅

**4. 上传的照片是否都要入册？**

- A. 全部入册（默认）
- B. 我会标记哪些照片可以不用
- C. 允许你提出建议，但最终由我决定

**5. 照片怎么上传？**

- A. 先上传 30–50 张代表照片做样稿（推荐）
- B. 按每批 50–80 张分批上传
- C. 一次上传全部照片

**6. 希望整本相册是什么节奏？**

- A. 留白较多，大图较多
- B. 疏密结合，有重点也有生活碎片（推荐）
- C. 图片丰富紧凑
- D. 看完照片后，由你推荐节奏

**6b. 是否有印刷预算或最多页数？（可跳过）**

- A. 暂时不限，优先保证照片舒展（推荐）
- B. 我有预算或页数上限：____
- C. 还不确定，先做样稿再估算

预算仅用于讨论篇幅取舍，不承诺未确认的印刷价格；页数需说明是单页还是跨页。

## 三、风格与文字

**7. 希望相册是什么视觉感觉？**

可以选择 2–4 个：干净、可爱、温暖、活泼、诗意、复古、zine 杂志感、手账感、极简，或由我根据照片推荐。用户也可以提供相册、海报或网页参考图。

若用户只说“zine”且参考图还不能明确方向，在第7题附一个短选择：A. 极简编辑式；B. 高饱和拼贴；C. 纸感手作；D. 看照片后推荐。已有明确偏好就不再问，将方向保存到 brief.visual。

**8. 文案从哪里来？**

- A. 我提供描述，你负责润色
- B. 你根据照片中能看到的内容写，不虚构具体经历
- C. 两者结合：有描述就润色，没有就适当补充（推荐）
- D. 尽量少写，只保留日期和标题

**9. 如果使用文字，希望是什么风格？**

可以选择 1–2 个：温柔诗意、可爱俏皮、日记口吻、幽默活泼、纪实克制、简短留白，或由我根据不同事件灵活决定（推荐）。同时询问中文、英文或中英混合。

## 四、照片处理与创意元素

**10. 是否允许基础照片优化？**

- A. 可以裁剪、提亮和统一色彩，但保留真实感（推荐）
- B. 只能提亮和调色，不能裁剪
- C. 不处理原图

**11. 是否希望根据照片内容加入贴纸？**

例如花、雪山、交通工具、食物或节日元素。

- A. 可以，适量点缀（推荐）
- B. 可以丰富一些
- C. 不需要贴纸

**12. 封面怎么制作？**

- A. 根据相册故事绘制专属插画封面（默认推荐）
- B. 使用我选中的照片
- C. 做纯文字或极简封面
- D. 看完照片后提供两种方向让我选择

默认先完成内页并审核整本故事，再用可用的 image 工具制作最终封面；小样先使用占位封面。选择照片或纯文字封面时遵循你的选择。

**13. 是否使用撕纸照片效果？**

它会保留真实照片，同时把部分边缘变成不规则纸张或插画结构。

- A. 只在特别合适的少数页面使用（推荐）
- B. 可以多使用一些
- C. 不使用

**14. 是否允许把部分照片制作成艺术衍生图？**

这种方式用于合适的照片、建筑、风景或章节过渡页。会评估七条创意路线，按你允许的处理与真实照片选择；不要求使用全部效果。

- A. 保留原图，衍生图只作背景或装饰（推荐）
- B. 特别合适时可以替换原图，但必须标出来供我审核
- C. 不制作艺术衍生图

**15. 是否需要“照片简化”设计？**

它会从照片提取颜色、轮廓或局部元素，制作成简洁的小卡片、色块画或抽象陪衬页。

- A. 可以，在适合的页面少量使用（推荐）
- B. 可以作为较明显的视觉特色
- C. 不需要

## After the answer

1. Resolve any direct questions in the user's response, including upload strategy or format recommendations.
2. Ask a follow-up only when an unanswered ambiguity would materially change the sample.
3. Save every answer and accepted recommendation to `project/brief.json` before arranging photos.
4. Record whether each value was `explicit`, `recommended_accepted`, `inferred`, or still `unknown`.
5. Start with a representative sample when that route was chosen.
6. Never repeat this questionnaire for later batches or local revisions. Read the saved brief instead.
