# Plog workflow changes — v0.8.0

Standalone Plog now uses five image-led stages, conditional research/font work, integrated source-reference generation and optional complete-page finishing. Local components carry source maps as artwork layers. New completion records use version 2; legacy v1 remains readable. Ordinary albums retain their intake and seven-route batch policy. Original user prompts remain archived; transparent paper and one plant/flower are explicit adaptations. This release supersedes the GitHub 0.7.3 Plog workflow.

Default ordinary Plog now plans source/text/scene/gesture relationships, builds a light base and uses imagegen as its final visual implementation stage. Structural effects are optional and checked for project-local repetition. Per-generation pixel/source comparisons and mandatory intermediate inspection notes removed; actual provenance and one final normal/phone acceptance pass retained.
